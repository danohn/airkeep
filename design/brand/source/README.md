# Filament-loop source

`filament-loop.svg` contains the mark's editable silhouette. Preserve its proportions, circular opening, separating gap and tapered tip when making new variants.

The wordmark is separate from the mark. The logo lockups and GitHub artwork use DM Serif Display converted to vector outlines. The font's license is in [../fonts/OFL.txt](../fonts/OFL.txt).
