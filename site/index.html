Set up Airkeep

Both setups connect to one printer from an always-on computer on the same network. Have the printer’s LAN IP address, serial number and LAN access code ready.

Use hosted Airkeep

Run a small agent on your network. The hosted dashboard stores readings and checks alert rules when your apps are closed.

  1. Create an account and follow the email link to verify your address and set a password.
  2. With uv installed, run uvx airkeep on the printer’s network. Open the local setup link it prints and enter the printer details.
  3. Follow the pairing link, sign in to the dashboard, and approve the code shown in setup.
