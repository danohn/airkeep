Install your desk display

For the Waveshare ESP32-S3-Touch-AMOLED-1.8 V2. Use desktop Chrome or Edge and a USB data cable. You’ll also need an Airkeep relay with a trusted HTTPS certificate and an account on that relay.

Set up your relay ↗

  1. Install firmware

    Factory installation replaces the current firmware and clears Wi-Fi settings and pairing.

    Checking for a firmware release…

    Download firmware SHA-256 checksum Command-line flashing
    Build from source ↗

  2. Configure over USB

    Close the flasher dialog, then connect to the running display. To change settings later, return to this step. Your settings go directly to the display over USB.

    Use a 2.4 GHz network. Leave the password blank for an open network.

  3. Pair your display

    When the display connects, tap Pair display. Scan the QR code or visit dashboard.airkeep.io/device and enter the displayed code. Sign in and approve the display to start seeing readings. For a self-hosted relay, use its /device page.

Connection or installation trouble?

Close other serial monitors and check that the cable supports data. If the flasher can’t find the board, hold BOOT while resetting it, then release BOOT. After flashing, reset it normally before connecting for setup.

If Wi-Fi fails, reconnect over USB and check the network name and password. If pairing fails, check that the relay is reachable from the display’s network, its HTTPS certificate is trusted, and the display can sync its clock.
